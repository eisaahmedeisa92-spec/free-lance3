Project guidelines

How a project's tier is decided

Every request is classified as Easy, Medium, or Hard based on two things: how many pages the site needs, and how much code each page runs to. Read this before submitting a project request.

EASY

Small, focused sites

≤ 2 pages total
≤ 400 lines of code per page

A landing page, a simple portfolio, or a single form-driven page usually falls here.

MEDIUM

Multi-page sites

3–5 pages total
≤ 600 lines of code per page

A small business site with several sections, or a site like this one, typically falls here.

HARD

Larger builds

6+ pages, or
600+ lines on any single page

Anything past the Medium limits — more pages, deeper functionality, or longer per-page code — is scoped as Hard and quoted individually.

A few extra notes

  • "Lines of code" is counted per file, so a page's HTML and its linked CSS are measured separately against the same limit.
  • If a request sits right at the edge of a limit, it's rounded up to the safer tier so the quote stays accurate.
  • Adding pages or features after work has started can move a project into a higher tier and will be quoted separately, as covered in the policy on the home page.
  • Still unsure where your idea fits? Describe it as clearly as you can in the request form — the classification gets confirmed with you before work begins.
